The toolchain check below only needs the Arduino IDE and the built-in Servo library. The robot's own sketch, covered later in this section, needs one additional library, installed at that point. Prior experience blinking an LED on an Arduino is sufficient preparation.

Installing the IDE

  1. Download the Arduino IDE 2.x

    From arduino.cc/en/software. Version 2.3 or newer was used in development. The legacy 1.8.x will compile the sketch but lacks the serial plotter improvements useful during calibration.

  2. Add the AVR board package

    Tools → Board → Boards Manager → search "Arduino AVR Boards" → Install. This bundles the toolchain for the ATmega328P on the Nano. Wait for it to finish before continuing.

  3. Select the board and processor

    Tools → Board → Arduino AVR Boards → Arduino Nano. Then Tools → Processor → ATmega328P (Old Bootloader) if the kit Nano was supplied as a clone (most are); otherwise ATmega328P. If uploads fail with an avrdude timeout, switching between the two options resolves the issue in most cases.

  4. Plug in the Nano, identify the serial port

    Connect the USB-C cable. Tools → Port should now show a new entry: /dev/cu.usbserial-* on macOS, COM# on Windows, /dev/ttyUSB# on Linux. Select it. If nothing appears, see the USB cable warning in Section 02.

  5. Verify with Blink

    File → Examples → 01.Basics → Blink. Upload it. The Nano's onboard LED (next to D13) should start blinking at 1 Hz. If this succeeds, the toolchain is correctly configured. If it does not, resolve toolchain issues at this stage rather than during the more complex sketch.

Setting up the Quadruped

Two sketches carry the robot from bare assembly to a walker: one that centres every servo before the rocker arms go on, and one that runs the robot itself. Both live in the project repository under assets/ino_code/ and are linked below as downloads rather than reproduced inline, so there is no risk of a character mistyped from a printed page.

Warning · The Nano must come off the PCB to upload

Before uploading either sketch below, lift the Nano out of its socket on the PCB. Connect it to the laptop by USB on its own, upload, then reseat it in the socket once the upload finishes. Uploading while the Nano is still seated on the PCB is the single most important thing to avoid in this section.

1. Calibrating the Servos to 90°

Before the servo rocker arms are attached, every servo must be driven to a known, identical position. Fitting a rocker arm to a horn that has not been centred bakes the misalignment into the mechanical assembly, where it can no longer be corrected afterward.

  1. Download the calibration sketch

    quadruped_legs_correction.ino↓ and open it in the Arduino IDE.

  2. Remove the Nano and upload

    Lift the Nano out of its PCB socket, connect it to the laptop by USB, and upload. The sketch drives all twelve servo positions to 90° and holds them there.

  3. Reseat the Nano, set the limbs, and fit the rocker arms

    Reseat the Nano in its PCB socket so the servos hold their position on PCB power rather than the bench USB connection. With each servo steady, set the limb to the 90° position against its horn, then fit the rocker arm so it reads neutral at that position.

2. Uploading the Robot Source Code

Once assembly of the robot is complete, it is ready for the sketch that actually walks it.

  1. Install the FlexiTimer2 library

    The robot sketch schedules its servo updates with FlexiTimer2, which does not ship with the Arduino IDE. Download it from that repository, install it via Sketch → Include Library → Add .ZIP Library, and see the Arduino Playground page for further background on the library.

  2. Download the robot sketch

    quadruped_spider_robot_code.ino↓ and open it in the Arduino IDE.

  3. Check the servo-to-pin assignments

    Before uploading, confirm each servo motor matches the pin number wired to its corresponding foot, against the channel map in Section 06. A mismatch here produces a leg that moves the wrong way rather than a compile error.

  4. Remove the Nano and upload

    As in Step 1: lift the Nano out of its PCB socket before connecting USB. Verify, then upload.

  5. Reseat the Nano and power up

    Once the upload finishes, reseat the Nano in its socket and reconnect the battery. The serial monitor will print initialisation messages ending in "Robot initialization Complete," after which the robot runs its demonstration sequence: stand, step forward, step back, turn left, turn right, wave, shake, and sit.
